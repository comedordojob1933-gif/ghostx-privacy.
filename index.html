Política de Privacidade do GhostX

Última atualização: 9 de outubro de 2026

Esta Política de Privacidade explica como o bot GhostX (“bot”) pode recolher, utilizar e proteger informações quando é utilizado no Discord.

1. Informações que podemos recolher

Consoante as funcionalidades utilizadas e as permissões concedidas ao bot, poderão ser processados dados como o ID de utilizador do Discord, o ID do servidor, os IDs de canais e mensagens necessários para executar comandos, e as opções ou configurações do servidor. O bot não deve recolher dados que não sejam necessários para as suas funcionalidades.

2. Como utilizamos as informações

As informações são utilizadas para executar comandos, disponibilizar as funcionalidades do GhostX, guardar configurações quando necessário, resolver erros e proteger o funcionamento do bot.

3. Mensagens e dados pessoais

O tratamento de conteúdo de mensagens depende das funcionalidades e permissões efetivamente implementadas no bot. Não incluas nesta política promessas de que as mensagens nunca são lidas ou guardadas, a menos que isso seja verdade para o código e os serviços utilizados pelo GhostX.

4. Partilha de dados

Não vendemos dados pessoais. Os dados poderão ser tratados por serviços de alojamento ou outros fornecedores necessários para operar o bot, ou divulgados quando tal seja exigido por lei. A plataforma Discord também trata dados de acordo com as suas próprias políticas.

Política de Privacidade do Discord: https://discord.com/privacy.

5. Conservação e segurança

Os dados devem ser conservados apenas durante o período necessário à finalidade para que foram recolhidos. São adotadas medidas razoáveis para evitar acessos não autorizados, perda ou utilização indevida, embora nenhum sistema possa garantir segurança absoluta.

6. Direitos e pedidos

Para esclarecer dúvidas ou pedir informações sobre dados associados à utilização do GhostX, contacta o responsável pelo bot através do contacto indicado abaixo. Substitui o endereço de exemplo por um endereço de contacto que controles antes de publicar esta página.

Contacto: TEU-EMAIL@EXEMPLO.COM

7. Privacidade de menores

O GhostX não se destina a recolher intencionalmente dados pessoais além do necessário para funcionar. Se acreditares que foram fornecidos dados indevidos, contacta o responsável pelo bot.

8. Alterações a esta política

Esta política poderá ser atualizada para refletir alterações no bot ou nos requisitos aplicáveis. A versão mais recente será publicada nesta página, com a respetiva data de atualização.

9. Contacto

Para questões relacionadas com esta política, utiliza o contacto indicado na secção 6.
